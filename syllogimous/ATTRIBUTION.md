# Syllogimous v3 attribution

This directory contains an adapted snapshot of
[Syllogimous v3](https://github.com/soamsy/Syllogimous-v3) at commit
`9b56def41c4295259a80e655dacc3c1238437358`.

[4skinSkywalker](https://github.com/4skinSkywalker/),

statistics bridge, profile-import validation, removal of service-worker
unregistration and dynamic `eval`, generated feedback tones, Unicode direction
icons, and removal of unused or unlicensed themed media assets.
